# RetroPulse

**Classic games. A custom experience.**

RetroPulse is a browser-based retro gaming project featuring direct ROM uploads, customizable controls, and a dedicated SNES input display.

## Features

* **Browser-based gaming:** Play compatible games directly in your browser.
* **Direct ROM upload:** Load your own compatible ROM files through the website.
* **Physical controller support:** Play using a compatible connected gamepad.
* **Virtual controller:** Control games using the on-screen virtual controller.
* **SNES input display:** Visualize controller inputs in a classic SNES-inspired style.
* **Customizable input display:** Adjust its size and screen position.
* **Fullscreen mode:** Enjoy a more immersive gaming experience.
* **Persistent settings:** Input display preferences are saved locally in your browser.
* **Custom RetroPulse branding:** A dedicated interface designed for retro gaming.

## Getting Started

1. Open the RetroPulse website in your browser.
2. Upload a compatible ROM using the available upload option.
3. Wait for the game to load.
4. Start playing using a supported input method.

No manual ROM placement is required when using the hosted website.

## Controls

RetroPulse supports multiple ways to interact with games.

### Physical Controller

Connect a compatible gamepad and use it to control the game.

### Virtual Controller

Use the on-screen virtual controller to interact with the game without a physical gamepad.

### SNES Input Display

The input display visualizes controller inputs in real time. It is designed for monitoring inputs, recordings, and speedruns rather than directly controlling the game.

The display can show:

* D-Pad directions
* A, B, X and Y buttons
* Start and Select

## Input Display Customization

Tap the input display to access its settings.

* **Size:** Adjust the display size.
* **X Position:** Move the display horizontally.
* **Y Position:** Move the display vertically.

Settings are saved locally in your browser and can persist between visits on the same device and browser.
